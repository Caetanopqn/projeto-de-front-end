# Top 10 de Jogos Favoritos

Um projeto desenvolvido para a disciplina de **Desenvolvimento Front-End para Web**, utilizando HTML para criar um pequeno site dedicado aos meus jogos favoritos.

O projeto apresenta um **Top 10 de jogos**, organizado de acordo com minhas preferências, com uma página individual para cada jogo contendo informações, imagens, curiosidades e uma breve descrição de sua história e proposta.

## Jogos

1. Inscryption
2. Mewgenics
3. Neon White
4. The Return of Obra dinn
5. Fez
6. Pizza Tower
7. Celeste
8. Baba Is You
9. Faith
10. Puss!

Além dos jogos, o site possui uma página de **avaliação**, onde o visitante pode escolher seu jogo favorito, atribuir uma nota e deixar sua opinião.

## Conteúdos e recursos

O projeto foi desenvolvido utilizando diferentes elementos do HTML, incluindo:

* Estrutura semântica com `header`, `nav`, `main`, `section`, `article`, `aside` e `footer`
* Imagens utilizando `figure` e `figcaption`
* Áudio e vídeo
* Formulários
* Campos `date`, `file`, `color` e `range`
* Campos obrigatórios com `required`
* Campos com `placeholder`
* Sugestões utilizando `datalist`
* Informações expansíveis com `details` e `summary`
* Elementos como `mark`, `meter` e `progress`

## Tecnologias

* HTML5

## Objetivo

O objetivo do projeto é praticar a utilização de **HTML5 e seus elementos semânticos e interativos**, criando um site organizado enquanto apresento alguns dos jogos que mais gosto.
